## Convenciones de mantenimiento

1. **Código y pruebas** son la fuente de verdad sobre lo implementado. Si contradicen un documento, comprobar el código y corregir el documento en el mismo cambio.
2. Distinguir siempre: **implementado / verificado automáticamente / pendiente de validación manual / propuesto**.
3. Las cifras de balance, actividades, puntos y evaluación académica son **mecánicas ficticias**, no requisitos oficiales del SNII.
4. Mantener comentarios significativos en español, enlaces relativos y referencias a los módulos reales.
5. Las antiguas rutas `docs/00_...` a `docs/17_...` siguen siendo enlaces de compatibilidad hacia los originales archivados.
