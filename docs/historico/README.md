# Archivo histórico de especificaciones e iteraciones

Estos documentos históricos se preservan para conservar la trazabilidad, excepto las menciones a la denominación anterior del producto, que se normalizaron a Academic Pet por decisión de identidad. Algunos afirman que módulos «no existen» porque se redactaron **antes de que se implementaran**. **No deben usarse como la documentación actual.**

| Documentos | Alcance |
| --- | --- |
| `00_...` a `07_...` | Diseño inicial, tablas de balance tentativas, contratos propuestos y estructura imaginada |
| `08_...` y `09_...` | Primer MVP e indicaciones de publicación en aquella etapa |
| `10_...` y `11_...` | Conceptos visuales y guía de código en una iteración anterior |
| `12_...` a `14_...` | Iteraciones de bienestar, interfaz y animación |
| `15_...` a `17_...` | Historia de pedagogía, cinco pasos, escenarios y corrección de estaciones |

Los nombres originales de los 18 documentos se conservan en este directorio. Las rutas antiguas ubicadas directamente bajo `docs/` son páginas de enlace de compatibilidad.
