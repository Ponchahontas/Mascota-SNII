# Datos configurables — punto de extensión

Los catálogos de etapas, actividades, eventos, objetos, automatizaciones y normativa deben vivir separados de la lógica de los motores.

Antes de habilitar un conjunto de datos, validar:
- IDs únicos.
- Referencias existentes.
- Rangos y multiplicadores válidos.
- Transiciones de etapa posibles.
- Efectos de eventos permitidos.
- Estado de verificación de las fuentes normativas.

Los catálogos completos aún no están implementados.
