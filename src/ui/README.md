# Interfaz — punto de extensión

La interfaz futura debe:
- Leer modelos de vista, no modificar el estado persistente.
- Enviar comandos al coordinador y esperar resultados confirmados.
- Mostrar estados de carga, error y guardado real.
- Mantener controles de cuidado accesibles.
- Incluir alternativas para recursos visuales ausentes.
- Evitar que el color o la animación sean la única forma de transmitir información.

Los componentes visuales completos aún no están implementados.
